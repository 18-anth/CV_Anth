# 🌐 Portafolio Web Personal

Este es mi portafolio web desarrollado en React.js, diseñado para mostrar mis proyectos, certificaciones y más información profesional. Incluye un panel de administración para cargar nuevos contenidos.

---

## 📁 Estructura de Rutas

A continuación, se detalla cada una de las rutas del proyecto y su propósito:

### `/Project`

- **Descripción:** Página principal de proyectos. Muestra una galería de todos los proyectos destacados en los que he trabajado.
- **Componente:** `Project`

### `/Project/:id`

- **Descripción:** Página de detalle individual de cada proyecto. Muestra información más profunda, tecnologías utilizadas, capturas de pantalla, etc.
- **Componente:** `ProjectDetail`

---

### `/AboutMe`

- **Descripción:** Página que contiene una presentación personal, experiencia, habilidades técnicas y objetivos profesionales.
- **Componente:** `AboutMe`

---

### `/Certification`

- **Descripción:** Página que muestra una lista de certificaciones obtenidas, organizadas de manera visual e interactiva.
- **Componente:** `Certification`

### `/Certification/:id`

- **Descripción:** Página de detalle de una certificación específica. Permite ver información completa, el PDF asociado (si está disponible), y un enlace si corresponde.
- **Componente:** `CertificationDetail`

---

### `/Contact`

- **Descripción:** Página de contacto donde los visitantes pueden enviarme mensajes o preguntas directamente.
- **Componente:** `Contact`

---

### `/UploadCertification`

- **Descripción:** Panel de administración para subir nuevas certificaciones. Permite:
  - Ingresar el nombre de la certificación.
  - Añadir un enlace relacionado.
  - Cargar un archivo PDF.
  - Visualizar el PDF sin necesidad de descarga.
- **Componente:** `UploadCertification`

---

### `/UploadProject`

- **Descripción:** Panel de administración para añadir nuevos proyectos al portafolio. Permite incluir título, descripción, tecnologías usadas, imágenes, y más.
- **Componente:** `UploadProject`

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** React.js, Material UI
- **Backend:** Firebase (Authentication, Firestore, Storage)
- **Modelado 3D (en desarrollo):** Blender + AI
- **Responsive Design:** Adaptado a dispositivos móviles y escritorio

---

## 📌 Objetivo

Este portafolio busca reflejar mi evolución como desarrollador y servir como carta de presentación interactiva para oportunidades laborales, colaboraciones o simplemente para compartir lo que me apasiona crear.
